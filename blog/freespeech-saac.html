FreeSpeech SAAC: comunicador aumentativo en Vue 3 con WCAG 2.2 AA

Noviembre 2026 · Inclusión · Por Diego Mena

Sistema Aumentativo y Alternativo de Comunicación (SAAC) en Vue 3.5 + Vite con conformidad WCAG 2.2 AA, 345 pictogramas ARASAAC offline y SDK universal adaptable para LMS y portales web.

Las personas con discapacidades de la comunicación dependen de sistemas aumentativos y alternativos (SAAC/AAC) para expresarse, pero la mayoría de opciones comerciales son costosas o exigen apps instaladas. FreeSpeech SAAC es un comunicador de pictogramas que corre en el navegador, construido en Vue 3.5 + Vite y diseñado con conformidad WCAG 2.2 AA desde la base.

345 pictogramas ARASAAC offline

El vocabulario visual usa el catálogo ARASAAC, la referencia abierta en pictografía para comunicación aumentativa. Los 345 pictogramas se sirven localmente, así que el comunicador funciona sin conexión: un requisito crítico en aulas, zonas rurales o instituciones con redes restringidas.

Accesibilidad que se practica, no solo se predica

Ser una herramienta para personas con discapacidad obligaba a un estándar ejemplar: objetivos táctiles de al menos 24x24 px (2.5.8), contraste AA en todos los estados, navegación completa por teclado, regiones en vivo para la frase construida y síntesis de voz mediante la Web Speech API para vocalizar cada selección.

speak.ts
export function speak(phrase: string) {
  const utterance = new SpeechSynthesisUtterance(phrase);
  utterance.lang = 'es-CO';
  utterance.rate = 0.9;
  speechSynthesis.cancel(); // evita colas solapadas
  speechSynthesis.speak(utterance);
}

SDK universal con trigger personalizable

Además de la aplicación completa en freespeech.a11ypro.tech, el proyecto incluye un SDK integrable en plataformas LMS y portales web. El anfitrión puede configurar el disparador (botón, atajo de teclado o elemento propio) sin tocar el núcleo del comunicador.

Por qué importa

Comunicarse es un derecho. Un SAAC web, gratuito, offline y accesible elimina las barreras económicas y técnicas que hoy dejan a muchas personas sin una voz alternativa. Publicarlo como open source busca que cualquier institución pueda desplegarlo y adaptarlo sin licencias.

El proyecto es open source en github.com/ingelectronicadj/freespeech.
