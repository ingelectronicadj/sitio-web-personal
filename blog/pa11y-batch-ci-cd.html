Pa11y Batch: auditorías WCAG masivas en español con CI/CD

Noviembre 2026 · Automatización · Por Diego Mena

Suite Web Studio, CLI y CI/CD para auditorías automatizadas de accesibilidad con axe-core y HTML_CodeSniffer en español, vista ejecutiva para Stakeholders, inspección visual del DOM y artefactos JUnit.

Auditar una URL es fácil; auditar quinientas con trazabilidad es otra cosa. Pa11y Batch nace para escalar las auditorías automatizadas: ejecuta axe-core y HTML_CodeSniffer sobre lotes completos de URLs y consolida los resultados en reportes en español pensados tanto para perfiles técnicos como para dirección.

Dos motores, una matriz

Cada URL se evalúa con axe-core y con HTML_CodeSniffer de forma independiente. Correr dos motores reduce falsos negativos y permite contrastar criterios cuando las reglas se solapan: si ambos reportan el mismo elemento, la confianza del hallazgo aumenta; si divergen, el auditor humano decide con contexto.

Vista ejecutiva para stakeholders

El reporte incluye una vista agregada orientada a perfiles no técnicos: tendencia de conformidad por nivel WCAG, distribución de severidades y evolución entre ejecuciones. Junto a ella, la vista técnica ofrece inspección visual del DOM con capturas y selectores precisos para cada violación.

CI/CD con artefactos JUnit

La suite emite reportes en formato JUnit XML, el estándar que entienden Jenkins, GitLab CI, GitHub Actions y Azure DevOps. Esto permite convertir la accesibilidad en una puerta de calidad: el pipeline falla si aparecen violaciones por encima del umbral configurado.

pipeline.yml
a11y_audit:
  script:
    - pa11y-batch --urls sitemap.txt --runners axe,htmlcs \
        --level WCAG2AA --reporter junit --out reports/
  artifacts:
    reports:
      junit: reports/a11y-*.xml

Web Studio y reportes en español

Sobre el motor CLI se monta Pa11y Batch Web Studio, una interfaz web para lanzar auditorías sin terminal. Uno de sus diferenciales es que los hallazgos, las descripciones de reglas y las recomendaciones se entregan íntegramente en español, algo que las herramientas originales no ofrecen.

El proyecto es open source y está disponible en github.com/ingelectronicadj/pa11y_batch.
