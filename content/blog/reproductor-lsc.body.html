Para la comunidad sorda colombiana, la Lengua de Señas Colombiana (LSC) es lengua primera y el español escrito es una segunda lengua. Un reproductor de video convencional no basta para aprenderla: hace falta ver la seña desde varios ángulos, repetir fragmentos y consultar el glosario. Reproductor LSC nació para eso.

Sincronización multicámara

La seña es tridimensional: involucra manos, expresión facial y orientación corporal. El reproductor reproduce dos o más flujos de video en perfecta sincronía (frontal y lateral), permitiendo alternar o combinar vistas sin perder el punto temporal, algo que requiere control preciso de la API HTMLMediaElement.

Bucle A-B para la práctica

Aprender una seña exige repetición. El modo bucle A-B permite marcar un punto de inicio y uno de fin y reproducir ese fragmento en ciclo, sin intervención, hasta dominar la producción. El control se expone tanto a ratón como a teclado, con anuncios en región en vivo del rango seleccionado.

loopAB.js
video.addEventListener('timeupdate', () => {
  if (loopB !== null && video.currentTime >= loopB) {
    video.currentTime = loopA; // reinicia el fragmento
  }
});

Glosario interactivo con autoevaluación

El componente pedagógico se completa con un glosario de señas navegable y un modo autoevaluación que oculta la glosa y reta al estudiante a reconocer la seña mostrada. Los resultados se anuncian en una región role="status" para no perder el contexto.

Accesible también para quien no usa lengua de señas

La propia interfaz del reproductor cumple los principios que predica: controles nativos operables por teclado, foco visible, etiquetas en español y LSC, y compatibilidad con lectores de pantalla. El objetivo es que la herramienta sirva tanto a docentes oyentes como a estudiantes sordos.

El proyecto es open source en github.com/ingelectronicadj/ReproductorLSC.
